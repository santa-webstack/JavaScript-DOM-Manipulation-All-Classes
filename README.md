# 🌐 JavaScript DOM Manipulation - Master Collection

This repository is a dedicated collection of all my learning modules, exercises, and projects related to **Document Object Model (DOM) Manipulation**. It documents my journey of turning static websites into dynamic, interactive web applications using pure JavaScript.

## 🚀 Key Learning Objectives

Through these modules, I am mastering the following core concepts:

* **DOM Selectors:** Efficiently targeting HTML elements using `ID`, `Class`, `Tag`, and `querySelector`.
* **Content & Style Manipulation:** Dynamically updating text, HTML structure, and CSS styles on the fly.
* **DOM Traversing:** Navigating through the DOM tree (Parent, Child, and Sibling relationships).
* **Event Handling:** Implementing interactive features using `click`, `input`, `submit`, and keyboard events.
* **Dynamic UI Creation:** Building, appending, and removing HTML elements programmatically.
* **Advanced Patterns:** Understanding Event Bubbling, Capturing, and Event Delegation.

## 📂 Folder Structure
The repository is organized into 15+ modules covering:
1.  **DOM Introduction** - Understanding the window and document objects.

4.  **The Event Listeners** - Making the web interactive.
